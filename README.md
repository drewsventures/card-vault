# Card Vault — Phase 1

Mobile-first inventory app reading live from Supabase (project: card-inventory-platform).
Static single-file app. To get a live URL:

- Netlify Drop: go to app.netlify.com/drop and drag this folder in. Instant URL.
- or Vercel: vercel.com/new, import/drag, deploy.

Read-only for now (RLS locked). Login/auth + write actions come in the next pass.
